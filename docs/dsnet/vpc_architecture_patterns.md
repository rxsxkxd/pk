# VPC 構成パターン概念図（EC2 / ECS / VPC 内 Lambda）

3 パターンとも VPC の骨格は共通で、2 AZ × 3 層（Public / Private app / Private DB）のサブネットからなる。データの流れも共通で、フロント（CloudFront）→ アプリ → RDS と、アプリ → S3 の 2 つ。パターン間で違うのは、アプリ層の置き方と外へ出る経路だけ。

- 概念図なので、CIDR・リソース名・ポート番号・ルールの詳細は書いていない。
- 図中のラベルは等幅で揃えるため英語にしている。
- SVG 版は後で追記する。

## 図の読み方

| 表記 | 意味 |
|---|---|
| `VPC` の箱 | VPC。この中がプライベートネットワーク |
| `... subnet` の箱 | サブネットの層。左右の `AZ-a` / `AZ-c` は、同じ層のサブネットを AZ ごとに 1 つずつ持つことを表す |
| `route->...` | その層のルートテーブルの主な宛先（IGW / NAT GW / VPC エンドポイント / VPC 内のみ） |
| `NACL` | その層のサブネットに付くネットワーク ACL（サブネット単位、ステートレス） |
| `[SG]` | そのリソースに付くセキュリティグループ（リソース単位、ステートフル） |
| `VPCE` | VPC エンドポイント。Gateway 型は S3 用、Interface 型は他の AWS サービス用 |
| 矢印 | 通信を始める側 → 受ける側 |

## 共通の考え方

- **Public subnet:** インターネットと直接やり取りするものだけを置く（ALB、NAT GW）。ルートテーブルは IGW へ向ける。
- **Private app subnet:** アプリを置く。外へ出る通信は NAT GW を通り、S3 などの AWS サービスへは VPC エンドポイントを通る。
- **Private DB subnet:** RDS を置く。ルートは VPC 内のみで、外とは通信しない。
- **SG の連鎖:** 前段の SG からの通信だけを許可する（ALB の SG → アプリの SG → DB の SG）。
- **NACL:** サブネット単位の補助的な防御として使う。SG だけで制御し、NACL は既定（全許可）のままにすることも多い。
- **S3 の使い分け:** 静的ファイルは CloudFront の OAC 経由で配信し、アプリデータは Gateway VPCE 経由で読み書きする。

## パターン 1: EC2

```text
                        Users (Internet)
                               | HTTPS
                     +---------v---------+   OAC    +--------------------+
                     |    CloudFront     |--------->| S3: static files   |
                     +-------------------+          +--------------------+
                               | HTTPS
+- VPC ------------------------|---------------------------------------------------+
|                          +---v---+                                               |
|                          |  IGW  |                                               |
|                          +-------+                                               |
|                              |                                                   |
| +- Public subnet ------------|--- route->IGW | NACL -------+                     |
| | AZ-a                       |                       AZ-c  |                     |
| |                  +---------v---------+                   |                     |
| |   [NAT GW]       |     ALB [SG]      |    [NAT GW]       |                     |
| |                  +-------------------+                   |                     |
| +----------------------------|-----------------------------+                     |
|                              | HTTP                                              |
| +- Private app subnet -------|--- route->NAT,VPCE | NACL --+                     |
| | AZ-a                       |                       AZ-c  |                     |
| |           +----------------+---------------+             |                     |
| |  +--------v---------+             +--------v---------+   | +------------------+|   +------------+
| |  |    EC2 [SG]      |             |    EC2 [SG]      |---->| S3 Gateway VPCE  |--->|S3: app data|
| |  +------------------+             +------------------+   | +------------------+|   +------------+
| |           |                                |             |                     |
| +-----------|--------------------------------|-------------+                     |
|             +----------------+---------------+                                   |
|                              | DB connection                                     |
| +- Private DB subnet --------|--- route:local | NACL ------+                     |
| |           +----------------+                             |                     |
| |  +--------v---------+             +------------------+   |                     |
| |  |   RDS primary    | <- sync ->  |   RDS standby    |   |                     |
| |  |      [SG]        |             |      [SG]        |   |                     |
| |  +------------------+             +------------------+   |                     |
| | AZ-a                                               AZ-c  |                     |
| | DB subnet group = AZ-a + AZ-c                            |                     |
| +----------------------------------------------------------+                     |
+----------------------------------------------------------------------------------+
```

- ALB は両方の AZ の Public subnet にまたがる。ターゲットは Auto Scaling グループの EC2。
- EC2 にはパブリック IP を付けない。外へ出る通信は NAT GW を通る。
- RDS は Multi-AZ 構成（プライマリとスタンバイ）。

## パターン 2: ECS（Fargate）

```text
                        Users (Internet)
                               | HTTPS
                     +---------v---------+   OAC    +--------------------+
                     |    CloudFront     |--------->| S3: static files   |
                     +-------------------+          +--------------------+
                               | HTTPS
+- VPC ------------------------|---------------------------------------------------+
|                          +---v---+                                               |
|                          |  IGW  |                                               |
|                          +-------+                                               |
|                              |                                                   |
| +- Public subnet ------------|--- route->IGW | NACL -------+                     |
| | AZ-a                       |                       AZ-c  |                     |
| |                  +---------v---------+                   |                     |
| |   [NAT GW]       |     ALB [SG]      |    [NAT GW]       |                     |
| |                  +-------------------+                   |                     |
| +----------------------------|-----------------------------+                     |
|                              | HTTP                                              |
| +- Private app subnet -------|--- route->NAT,VPCE | NACL --+                     |
| | AZ-a                       |                       AZ-c  |                     |
| |           +----------------+---------------+             |                     |
| |  +--------v---------+             +--------v---------+   | +------------------+|   +------------+
| |  |  ECS task [SG]   |             |  ECS task [SG]   |---->| S3 Gateway VPCE  |--->|S3: app data|
| |  +------------------+             +------------------+   | +------------------+|   +------------+
| |           |                                |             |                     |
| +-----------|--------------------------------|-------------+ +------------------+|
|             +----------------+---------------+               |Interface VPCE    ||
|                              | DB connection                 |ECR, Logs,        ||
| +- Private DB subnet --------|--- route:local | NACL ------+ |Secrets Manager   ||
| |           +----------------+                             | |                  ||
| |  +--------v---------+             +------------------+   | |(ENI: app subnet) ||
| |  |   RDS primary    | <- sync ->  |   RDS standby    |   | +------------------+|
| |  |      [SG]        |             |      [SG]        |   |                     |
| |  +------------------+             +------------------+   |                     |
| | AZ-a                                               AZ-c  |                     |
| | DB subnet group = AZ-a + AZ-c                            |                     |
| +----------------------------------------------------------+                     |
+----------------------------------------------------------------------------------+
```

- タスクごとに ENI と SG を持つ（awsvpc モード）。それ以外はパターン 1 と同じ形。
- イメージの取得（ECR）、ログ、シークレットのために Interface VPCE を置く。Interface VPCE を置かず、NAT GW 経由にすることもできる。

## パターン 3: VPC 内 Lambda

```text
                        Users (Internet)
                               | HTTPS
                     +---------v---------+   OAC    +--------------------+
                     |    CloudFront     |--------->| S3: static files   |
                     +-------------------+          +--------------------+
                               | HTTPS
                     +---------v---------+
                     |    API Gateway    |
                     +-------------------+
                               | invoke
                     +---------v---------+
                     |  Lambda function  |
                     +-------------------+
                               | Hyperplane ENI (outbound only)
+- VPC ------------------------|---------------------------------------------------+
| +- Private app subnet -------|--- route->NAT,VPCE | NACL --+                     |
| | AZ-a                       |                       AZ-c  |                     |
| |           +----------------+---------------+             |                     |
| |  +--------v---------+             +--------v---------+   | +------------------+|   +------------+
| |  |  ENI [SG]        |             |  ENI [SG]        |---->| S3 Gateway VPCE  |--->|S3: app data|
| |  +------------------+             +------------------+   | +------------------+|   +------------+
| |           |                                |             |                     |
| +-----------|--------------------------------|-------------+                     |
|             +----------------+---------------+                                   |
|                              | DB connection                 +- Public subnet --+|
| +- Private DB subnet --------|--- route:local | NACL ------+ | [NAT GW] x AZ    ||
| |                            |                             | | route->IGW       ||
| |                +-----------v-----------+                 | | NACL             ||
| |                |  RDS Proxy [SG]       |                 | |                  ||
| |                +-----------------------+                 | | (only if Lambda  ||
| |                   |                                      | |  needs internet) ||
| |  +----------------v-+             +------------------+   | |                  ||
| |  |   RDS primary    | <- sync ->  |   RDS standby    |   | +------------------+|
| |  |      [SG]        |             |      [SG]        |   |          |          |
| |  +------------------+             +------------------+   |      +---+---+      |
| | AZ-a                                               AZ-c  |      |  IGW  |      |
| | DB subnet group = AZ-a + AZ-c                            |      +-------+      |
| +----------------------------------------------------------+                     |
+----------------------------------------------------------------------------------+
```

- Lambda 本体は VPC の外（Lambda サービス側）で動き、VPC には ENI だけが置かれる。ENI は外へ出ていく通信専用なので、ALB も、ENI の SG のインバウンドも不要。
- 入口は VPC 外の API Gateway。
- インターネットに出る必要があるときだけ、NAT GW と Public subnet を置く。
- 同時実行で DB 接続が増えるため、RDS Proxy を挟む。

## 3 パターンの違い

| 項目 | EC2 | ECS（Fargate） | VPC 内 Lambda |
|---|---|---|---|
| 入口 | CloudFront → ALB | CloudFront → ALB | CloudFront → API Gateway |
| VPC 内のアプリ側リソース | EC2 インスタンス | タスクの ENI | Lambda の ENI |
| Public subnet に置くもの | ALB、NAT GW | ALB、NAT GW | NAT GW のみ（不要なら Public subnet ごと省略） |
| Interface VPCE | 任意 | ECR などで使うことが多い | 任意 |
| RDS への接続 | 直接 | 直接 | RDS Proxy 経由 |
