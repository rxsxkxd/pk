# 本番で 80・443 番を絞る前に確認すること

> 位置付け: [踏み台サーバーから入れる手順](./bastion-install-commands.md) を本番に流す前に確認が要ることの一覧。Let's Encrypt の更新への対応（ステップ 7）と、一覧の更新（`make-refresh.sh`）は、確認が済む前に、下の「今の想定」で実装してある。確認の結果が想定と違えば、「違ったとき」の列のとおり直す。
>
> 状態: どの項目もまだ確認していない（2026-11-09）。確認したら「結果」の列に、日付と内容を書く。
>
> 作成日: 2026-11-09

## 確認の順番

1. 踏み台サーバーの配置と流し方を確かめ（L13）、セキュリティグループと DNS を見る（L5・L6・L8）。決めてもらうことを決める（L14・L15）
2. ステップ 1 を 1 台に流す（G6・G7・G8）
3. ステップ 7-1 を流す（L1〜L4・L9〜L12）。L4 で転送があれば、先に Apache を直す
4. ステップ 2〜4 を 1 台に流し、**間を空けずに**ステップ 7-2・7-3 を流す
5. その台で `sudo certbot renew --dry-run` を流す（L7）
6. ステップ 5・6 の後に再起動して確かめる（G9）
7. 問題がなければ、ほかの台に広げる
8. 実際の更新の後に、`cert-expiry-check.sh` で残り日数を確かめる（L16・L17）
